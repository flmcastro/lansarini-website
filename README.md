# LANSARINI Piercing & Beauty Studio

Site portfolio para **Priscila Lansarini**, desenvolvido em **Next.js + Tailwind CSS + Framer Motion**.

O site apresenta:

- Hero cinematográfico
- Seção About (Sobre o Estúdio)
- Experiência (Piercing & Beauty Styling)
- Galeria Editorial
- Serviços oferecidos
- Feed Instagram (placeholders)
- CTA (Chamada para Agendamento)
- Footer minimalista

---

## 🛠 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) — Framework React moderno
- [Tailwind CSS](https://tailwindcss.com/) — Estilização elegante e responsiva
- [Framer Motion](https://www.framer.com/motion/) — Animações suaves e cinematográficas
- React 18+ / Node.js 20+
